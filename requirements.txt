# DOS ENTORNOS (elige run_scanner.bat):
#   venv311  = Python 3.11  ->  MODO REAL con IQ Option  (PRODUCCION)
#   venv     = Python 3.14  ->  MODO SIMULACION (sin broker)
#
# run_scanner.bat usa venv311 en primer lugar (modo REAL).
# Para el modo REAL se necesita la libreria clasica iqoptionapi
# (expone  from iqoptionapi.stable_api import IQ_Option).
# NO esta en PyPI y ademas exige Python <= 3.11; se instala desde GitHub:
#
#   venv311\Scripts\python -m pip install ^
#       https://github.com/iqoptionapi/iqoptionapi/archive/refs/heads/master.zip
#
# NOTA sobre el cliente websocket: iqoptionapi declara
# 'websocket-client==0.56', pero funciona correctamente con la version
# moderna (1.x), que si tiene ruedas para Python 3.11. Por eso se instala
# 'websocket-client' SIN fijar version. 'websockets' (otro paquete DISTINTO,
# el asincrono) lo necesita uvicorn para servir el panel en vivo.
